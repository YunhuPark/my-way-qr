# 내 방식 QR 사용 방법

공개 주소: https://my-way-qr.onrender.com/

> 무료 호스팅이라 15분 동안 접속이 없으면 잠듭니다. **시작 10분 전에 주소를 한 번 열어 두세요.** (처음 열릴 때 30~60초 걸릴 수 있음)

## 1. 기본 사용 (시연·설명용)

> **화면 구성 (3단계):** ① 말하기(🎤 말로 입력 또는 자주 쓰는 말 버튼 → AI로 설정하기) → ② 확인하기(6개 설정과 미리보기, 직접 고칠 수 있음) → ③ 내 QR. 🎤는 브라우저 음성인식을 쓰며 음성이 브라우저 회사 서버로 전송될 수 있다. 지원하지 않는 브라우저에서는 휴대폰 키보드의 마이크 버튼을 쓴다.

1. **내 화면 설정 만들기** — 주소를 열면 "내 화면 설정 만들기" 화면이 나옵니다.
   - **말로 알려주기:** 칸에 원하는 방식을 쓰고 **AI로 설정하기**를 누릅니다.
     예) "글씨는 아주 크게, 어려운 말은 쉽게, 천천히 하나씩 보고 싶어요"
     - "AI가 설정했어요"가 뜨면 AI가 처리한 것입니다. "기본 규칙으로 설정했어요"가 뜨면 AI가 아니라 키워드 규칙으로 처리된 것입니다.
     - 이름·연락처 같은 개인정보는 쓰지 마세요. 입력 문장은 외부 AI 서비스로 전송될 수 있습니다.
   - **직접 고르기:** 글자 크기, 쉬운 말, 고대비, 소리로 읽기, 한 단계씩, 시간 연장을 체크합니다. AI로 설정한 뒤에도 고칠 수 있습니다.
   - 오른쪽 **미리보기**에서 글자 크기와 색 대비가 바로 보입니다.
2. **QR 사용하기**
   - 휴대폰 카메라로 QR을 찍으면 같은 설정으로 키오스크 화면이 열립니다.
   - 한 기기에서만 보려면 **"이 설정으로 키오스크 체험"** 버튼을 누릅니다.
3. **키오스크 체험**
   - 위쪽 탭에서 **카페 주문 / 민원서류 발급 / 병원 접수**를 고릅니다.
   - **기본 화면**은 보통 키오스크처럼 작은 글씨와 어려운 말, 30초 제한시간이 있습니다.
   - **내 방식 화면**은 만든 설정이 적용됩니다. (프로필 링크로 열었을 때만 눌립니다. 회색이면 내 화면 설정 만들기에서 다시 여세요.)
   - 두 화면을 번갈아 눌러 비교하면 효과가 바로 보입니다.
4. **내 방식 화면에서 바뀌는 것**
   - 글자 크기: 보통 1배 → 크게 1.4배 → 아주 크게 1.8배 → 가장 크게 2.2배
   - 쉬운 말: 관공서식 문구가 일상어로 바뀜 (AI 변환, 하단에 AI/사전 표시)
   - 고대비: 검은 바탕에 흰 글씨, 선택한 버튼은 노란색
   - 한 단계씩: 한 번에 질문 하나만 보임, "뒤로 가기" 버튼 제공
   - 시간 연장: 제한시간 30초 → 120초
   - 소리로 읽기: 🔊 버튼(또는 단계가 넘어갈 때 자동)으로 읽어 줌

## 1-2. AI 화면 변환 (임의의 키오스크 화면을 바꿔 보기)

제안자 답변서의 "AI가 화면을 실시간으로 변환해야 한다"에 대응하는 기능입니다. 미리 만든 3종이 아니라 **새로 붙여넣은 화면**을 AI가 바꿉니다.

1. 내 화면 설정 만들기 화면 맨 아래 **"4. 어떤 키오스크든 AI로 바꿔 보기"**의 버튼을 누릅니다. (지금 만든 프로필이 이어집니다.)
2. 실제 키오스크의 질문·선택지·안내문을 칸에 붙여넣습니다. (**식당 주문 예시 넣기** 버튼으로 연습 가능, 최대 1,500자)
3. **AI로 화면 변환**을 누릅니다. 10~30초 걸릴 수 있습니다.
4. 결과를 확인합니다.
   - **숫자 검사:** 가격·수량 같은 숫자가 원문과 같은지 자동으로 검사합니다. **통과하지 못하면 체험 버튼이 막힙니다.** 다시 변환하세요.
   - **AI가 한 일:** 단계를 어떻게 나눴는지, 어떤 선택지를 직원 도움으로 표시했는지 설명합니다.
   - **단계별 미리보기:** 원문 → 쉬운 말 대조표
5. **이 화면으로 키오스크 체험**을 누르면 `✨` 탭으로 열립니다.
   - 프로필이 적용되어 한 번에 한 단계씩 진행됩니다.
   - 🙋 표시된 선택지는 직원 도움이 필요한 항목입니다.
   - 마지막에 **"선택한 내용이 맞는지 확인"** 화면이 나오고, 각 선택의 **원문**이 함께 보입니다. 확인 후 진행하면 끝납니다.

> 이 변환 화면은 데모용입니다. AI 결과는 매번 조금씩 다를 수 있습니다.
