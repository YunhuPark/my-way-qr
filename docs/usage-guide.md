# 내 방식 QR 사용 방법

공개 주소: https://my-way-qr.onrender.com/

> 무료 호스팅이라 15분 동안 접속이 없으면 잠듭니다. **시작 10분 전에 주소를 한 번 열어 두세요.** (처음 열릴 때 30~60초 걸릴 수 있음)

## 1. 기본 사용 (시연·설명용)

1. **프로필 만들기** — 주소를 열면 "프로필 만들기" 화면이 나옵니다.
   - **말로 알려주기:** 칸에 원하는 방식을 쓰고 **AI로 설정하기**를 누릅니다.
     예) "글씨는 아주 크게, 어려운 말은 쉽게, 천천히 하나씩 보고 싶어요"
     - "AI가 설정했어요"가 뜨면 AI가 처리한 것입니다. "기본 규칙으로 설정했어요"가 뜨면 AI가 아니라 키워드 규칙으로 처리된 것입니다.
     - 이름·연락처 같은 개인정보는 쓰지 마세요. 입력 문장은 외부 AI 서비스로 전송될 수 있습니다.
   - **직접 고르기:** 글자 크기, 쉬운 말, 고대비, 소리로 읽기, 한 단계씩, 시간 연장을 체크합니다. AI로 설정한 뒤에도 고칠 수 있습니다.
   - 오른쪽 **미리보기**에서 글자 크기와 색 대비가 바로 보입니다.
2. **QR 사용하기**
   - 휴대폰 카메라로 QR을 찍으면 같은 설정으로 키오스크 화면이 열립니다.
   - 한 기기에서만 보려면 **"이 설정으로 키오스크 체험"** 버튼을 누릅니다.
3. **키오스크 체험**
   - 위쪽 탭에서 **카페 주문 / 민원서류 발급 / 병원 접수**를 고릅니다.
   - **기본 화면**은 보통 키오스크처럼 작은 글씨와 어려운 말, 30초 제한시간이 있습니다.
   - **내 방식 화면**은 만든 설정이 적용됩니다. (프로필 링크로 열었을 때만 눌립니다. 회색이면 프로필 만들기에서 다시 여세요.)
   - 두 화면을 번갈아 눌러 비교하면 효과가 바로 보입니다.
4. **내 방식 화면에서 바뀌는 것**
   - 글자 크기: 보통 1배 → 크게 1.4배 → 아주 크게 1.8배 → 가장 크게 2.2배
   - 쉬운 말: 관공서식 문구가 일상어로 바뀜 (AI 변환, 하단에 AI/사전 표시)
   - 고대비: 검은 바탕에 흰 글씨, 선택한 버튼은 노란색
   - 한 단계씩: 한 번에 질문 하나만 보임, "뒤로 가기" 버튼 제공
   - 시간 연장: 제한시간 30초 → 120초
   - 소리로 읽기: 🔊 버튼(또는 단계가 넘어갈 때 자동)으로 읽어 줌

## 2. 사용자 테스트 진행 (진행자용)

기록지·동의서·과업 카드는 `docs/user-test-kit.docx`, 계획은 `docs/user-test-plan.md`를 보세요.

### 준비
- **기기 1대**(노트북이나 태블릿)를 참가자가 쓰고, 진행자는 옆에서 기록 패널을 조작합니다. 과업 중에는 **같은 기기, 같은 브라우저**를 쓰세요. (기록이 그 브라우저에만 저장됩니다.)
- 참가자 코드는 P1, P2처럼 코드만 씁니다. 이름은 어디에도 넣지 않습니다.

### 참가자 한 명당 순서
1. **테스트 모드로 접속:** `https://my-way-qr.onrender.com/?test=1&pid=P1`
   - 맨 위 설명 끝에 `[테스트 모드: 참가자 P1]`이 보이면 맞게 연 것입니다.
   - 이 주소로 연 뒤 만드는 QR과 "키오스크 체험" 링크는 모두 테스트 모드(기록 패널 표시)입니다.
2. **인사, 동의서 서명, 사전 질문**(기록지 상단) 후 **프로필 만들기**(기록지 A)
   - 참가자가 말한 선호를 입력하고 **AI로 설정하기**를 누릅니다. 필요하면 직접 고칩니다.
   - 걸린 시간, 도움 횟수, 선택된 설정을 기록지에 적습니다.
3. **QR 확인:** 참가자 휴대폰으로 QR이 열리는지 봅니다. 기록지의 "QR 이용 성공 여부"에 스스로/도움/실패를 적습니다.
   - 휴대폰에서 연 화면에도 기록 패널이 뜨고 **그 휴대폰에만** 기록됩니다. 과업은 휴대폰이 아니라 **노트북·태블릿**에서 하세요.
4. **노트북에서 "이 설정으로 키오스크 체험" 버튼**을 눌러 키오스크 화면으로 갑니다. 위에 **사용자 테스트 기록(진행자용)** 패널이 보입니다.
5. **과업 1** (배정표 참고)
   1. 위 탭에서 과업(카페/민원/병원)과 **기본 화면 또는 내 방식 화면**을 고릅니다. **과업을 시작하면 잠기니 먼저 정하세요.**
   2. 패널에 나온 **과업 카드 문구**를 확인하고, 참가자에게 **인쇄한 과업 카드**를 줍니다.
   3. **과업 시작(기록 시작)**을 누릅니다. 참가자가 화면을 조작합니다.
   4. 완료 화면이 뜨면 **자동 종료·저장**됩니다. 아래 표에 결과가 한 줄 추가됩니다.
   5. 진행 중 힌트를 주거나 참가자가 도움을 청하면 **도움·힌트 +1**을 누릅니다. 참가자가 포기하면 **중단(실패로 기록)**을 누릅니다.
6. **만족도 Q1~Q3**을 기록지에 적습니다.
7. **과업 2:** 5번과 같게, 다른 과업과 다른 화면으로 합니다.
8. **마무리 인터뷰** 3문항을 하고 기록지에 적습니다.
9. **다음 참가자:** 패널의 **참가자 코드** 칸을 P2로 바꾸거나 주소의 `pid=`를 바꿔 다시 엽니다. (과업 진행 중에는 코드 칸이 잠겨 있습니다.)
10. **모두 끝나면 CSV 내려받기**를 눌러 파일을 백업합니다. 파일은 엑셀로 열립니다.

### 파일럿(예행연습) 뒤에는
패널의 **기록 지우기**로 연습 기록을 지운 뒤 본 테스트를 시작하세요. 지우기 전에 CSV를 받아 두고 싶으면 먼저 내려받으세요.

### 기록되는 값
| 값 | 의미 |
|---|---|
| duration_sec | 과업 시작부터 완료까지(초) |
| result | success(도움 없이 완료) / assisted(도움받음) / failed(중단) |
| wrong | 과업 카드와 다르게 선택한 횟수 |
| backs | 뒤로 가기를 누른 횟수 |
| timeouts | 제한시간이 지나 처음으로 돌아간 횟수 |
| helps | 진행자가 힌트를 준 횟수 |
| selections | 선택 순서 (단계:선택지 번호) |

## 3. 자주 막히는 점

| 증상 | 원인과 해결 |
|---|---|
| 주소가 안 열리거나 오래 걸림 | 무료 호스팅이 잠든 상태. 30~60초 기다린 뒤 새로고침 |
| "내 방식 화면" 버튼이 회색 | 프로필 링크(`?p=`) 없이 열었음. 프로필 만들기에서 "이 설정으로 키오스크 체험"으로 다시 열기 |
| 기록 패널이 안 보임 | 주소에 `test=1`이 없음. `/?test=1&pid=P1`로 다시 시작 |
| 기록이 사라짐/안 보임 | 다른 기기·브라우저·시크릿 창을 썼음. 세션마다 CSV 백업 |
| 과업 중 처음 화면으로 돌아감 | 기본 화면의 30초 제한 때문. 정상 동작이며 `timeouts`에 기록됨 |
| "기본 규칙으로 설정했어요"가 뜸 | AI를 못 썼음(키 문제나 호출 한도 초과). `https://my-way-qr.onrender.com/healthz`에서 `"ai":true`인지 확인 |
| 소리가 안 남 | 기기 음량·무음 모드 확인, 🔊 버튼을 직접 누르기. 브라우저에 한국어 음성이 없으면 안 나올 수 있음 |
| 쉬운 말이 어색함 | AI가 변환한 문장이라 완벽하지 않음. 결제·동의 같은 중요 문구는 원문과 비교해서 확인 |
