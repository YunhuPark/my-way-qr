# 테스트 체크리스트 (3명)

## 시작 전 (한 번만)
- [ ] 노트북 충전, **계속 같은 브라우저**를 쓴다
- [ ] 서버 깨우기: `my-way-qr.onrender.com` 열어 두기
- [ ] 인쇄: 동의서 3부, 기록지 3부, 과업 카드 1세트, 펜
- [ ] 이름↔코드 대응표는 **종이에 따로** 적기 (기록지와 섞지 않기)
- [ ] 연습 한 번: `…/?test=1&pid=DEMO` → 과업 1개 → **CSV 내려받기** → **기록 지우기**

## 참가자 P1 — 카페(기본 화면) → 민원(내 방식 화면)
- [ ] `https://my-way-qr.onrender.com/?test=1&pid=P1` 열기
- [ ] 동의서 서명 (이름 없이 서명만)
- [ ] 참가자가 말한 대로 입력 → **AI로 설정하기**
- [ ] **이 설정으로 키오스크 체험** 누르기
- [ ] 탭 **카페 주문** + **기본 화면** 고르기 → **과업 시작** → 참가자가 하게 하기
- [ ] 탭 **민원서류 발급** + **내 방식 화면** 고르기 → **과업 시작** → 참가자가 하게 하기
- [ ] "어땠어요?" 한 줄 적기
- [ ] **CSV 내려받기**

## 과업 중에
- 탭과 화면은 **과업 시작 전에** 고른다 (시작하면 잠김)
- 도와줬을 때만 **도움 +1**, 포기하면 **중단**
- 도중에 앱·문구·방식을 바꾸지 않는다
