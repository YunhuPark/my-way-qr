# 시연 영상 구성안 (약 2분)

> **데모 시연 영상은 필수 제출물이다.** 공고문 8쪽 "제출 서류" 표: 필수는 ① 성과보고서 1부 ② 참가신청서 1부(서명 필수) ③ 웹 서비스 **테스트 URL** ④ **데모 시연 영상**(프로토타입 실행화면, **2~5분 내외, 주요 기능 시연**). 선택은 ⑤ 코드 저장소(GitHub) 링크 또는 AI 모델 코드 ⑥ 학습 데이터셋 요약 또는 샘플 결과물. (이전 버전에 "영상은 필수가 아니다"라고 적은 것은 공고문 8쪽을 놓친 오류였다.) 영상 파일의 전달 방식(첨부/링크)은 공고문에 없으므로 KEIT에 확인한다.

## 목적과 원칙
- **보여줄 것:** 문제 → 해결(QR) → 전/후 비교 → AI 화면 변환 → 안전장치 → 실제 테스트 결과. 심사 항목(문제정의·AI 구현 수준과 완성도·사회문제 기여·창의적 응용)에 하나씩 대응한다.
- **지킬 것**
  - 모의 화면임을 영상 안에 밝힌다. ("실제 키오스크가 아닌 모의 화면")
  - **테스트 결과 수치는 실제로 측정한 값만 넣는다.** 아직 없으면 그 장면은 만들지 않는다.
  - 참가자 얼굴은 동의를 받은 경우에만. 기본은 **화면과 손만** 촬영.
  - API 키, 개인 브라우저 탭·북마크·알림이 화면에 나오지 않게 한다.
- **접근성:** 주제가 접근성이므로 영상도 **한국어 자막을 화면에 입히고**, 글자는 크게 쓴다. (소리를 끄고 보는 사람이 많다.)

## 장면 구성 (총 약 2분)
| # | 시간 | 화면 | 자막·나레이션 |
|---|---|---|---|
| 1 | 0:00~0:12 | 기본 키오스크 화면(작은 글씨, 30초 카운트다운)을 휴대폰으로 보여줌. 시간이 줄어드는 걸 클로즈업 | "키오스크 앞에서 글자가 작고 말이 어려워 포기한 적, 있으신가요? 고령층과 장애인은 매번 직원의 도움을 청해야 합니다." |
| 2 | 0:12~0:27 | **내 화면 설정 만들기:** 칸에 "글씨는 아주 크게, 어려운 말은 쉽게, 천천히 하나씩" 입력 → AI로 설정하기 → 체크박스가 채워지고 QR이 뜸 | "내 방식 QR은 내가 편한 화면 방식을 QR 하나에 담습니다. 말로 설명하면 AI가 글자 크기, 쉬운 말, 한 단계씩 같은 설정으로 바꿔 줍니다. 장애명은 묻지 않고, 선호 설정만 담습니다." |
| 3 | 0:27~0:57 | 휴대폰으로 QR 찍기 → **같은 과업을 기본 화면(왼쪽)과 내 방식 화면(오른쪽)으로 나란히** (카페 주문 또는 병원 접수). 내 방식: 큰 글씨, 쉬운 말, 한 번에 한 질문, 🔊 소리 | "QR을 찍으면 키오스크 화면이 내 방식으로 바뀝니다. 왼쪽은 기존 화면, 오른쪽은 내 방식 화면입니다. 글씨는 커지고, 어려운 문구는 쉬운 말로, 질문은 한 번에 하나씩. 소리로 읽어 주고, 제한 시간도 넉넉합니다." |
| 4 | 0:57~1:25 | **AI 화면 변환:** 식당 주문 예시 붙여넣기 → 변환 → 결과(숫자 검사 통과, AI가 한 일, 단계별 원문→쉬운 말) → 키오스크 체험 → 현금 선택 시 🙋 직원 도움 | "처음 보는 키오스크 화면도 AI가 바꿉니다. 복잡한 안내문을 넣으면 질문을 하나씩 나누고, 쉬운 말로 바꾸고, 현금처럼 직원이 필요한 선택은 따로 표시합니다." |
| 5 | 1:25~1:37 | **확인 화면:** 선택한 내용과 **원문**이 함께 보이고, "가격·수량 숫자 검사를 통과했어요"가 보임 | "AI가 틀릴 수 있다는 전제로 만들었습니다. 가격 같은 숫자가 바뀌면 쓸 수 없고, 결제 전에는 원문과 함께 다시 확인합니다. 마지막 결정은 항상 사용자가 합니다." |
| 6 | 1:37~1:52 | **실제 테스트 결과**(막대 그래프 2개: 독립 완료율, 도움 요청). 하단에 "모의 화면 · 소규모 테스트 N명" | "[N]명이 병원 접수와 무인 결제 과제를 해 본 결과, 도움 없이 끝낸 비율은 [OO%에서 OO%]로, 도움 요청은 [OO회에서 OO회]로 달라졌습니다. 모의 화면에서 한 소규모 테스트입니다." |
| 7 | 1:52~2:00 | 로고 없이 제목 + QR + 주소 | "장애를 증명하지 않아도, 내 방식대로. 내 방식 QR." |

- **6번 장면은 사용자 테스트(10/22~10/26)가 끝나야 만들 수 있다.** 결과가 기대에 못 미쳐도 있는 그대로 쓴다. 결과를 못 얻으면 6번을 빼고 1분 40초 정도로 낸다.
- **분량 맞추기:** 한국어 나레이션은 초당 5~6글자 정도다. 위 문장은 장면당 길이에 맞췄지만, 실제로 읽어 보고 빨라지면 문장을 줄인다.

## 촬영 전 준비 (30분)
1. **서버 깨우기:** `https://my-way-qr.onrender.com/`를 촬영 10분 전에 열어 둔다. (무료 플랜은 15분 무접속이면 잠든다.)
2. **깨끗한 화면:** 크롬 새 프로필이나 시크릿 창에서 촬영한다. 개인 탭·북마크·알림 팝업이 안 보이게 하고, 방해 금지 모드를 켠다.
3. **브라우저 확대:** 125~150%로 키워서 글씨가 영상에서 읽히게 한다.
4. **시연 설정 미리 정하기:** 글자 1.8배 + 쉬운 말 + 한 단계씩 + 소리 + 시간 연장. 아래 링크를 열면 이 설정으로 바로 열린다. (생성기 장면은 직접 입력해서 찍고, 이 링크는 실패했을 때의 대비용)
   - `https://my-way-qr.onrender.com/kiosk.html?p=eyJmcyI6MS44LCJleiI6dHJ1ZSwiaGMiOmZhbHNlLCJ2byI6dHJ1ZSwic3QiOnRydWUsInRtIjp0cnVlfQ`
5. **AI 변환 예시:** 변환 화면의 **식당 주문 예시 넣기** 버튼을 쓴다. AI 결과는 매번 조금 다르므로 **변환을 2~3번 돌려 보고 가장 자연스러운 결과를 촬영**한다. (직원 도움이 과하게 붙은 결과는 피한다.)
6. **휴대폰:** 화면 녹화 기능을 켜고 터치 표시를 켠다. 무음 모드를 해제해 두면 🔊 소리가 같이 녹음된다.

## 촬영·편집
- **촬영 순서 추천:** 장면 2 → 3 → 4 → 5 → 1 순으로 찍는다. (같은 설정을 이어서 쓰기 때문)
- **PC 화면:** Windows는 `Win + G`(게임 바)나 OBS로 녹화할 수 있다. 창만 녹화하면 개인 정보가 덜 노출된다.
- **편집:** 윈도우 11에 들어 있는 Clipchamp 같은 무료 편집기로 충분하다. 자막은 영상에 **고정 삽입**하고, 큰 글씨와 높은 대비로 쓴다.
- **소리:** 본인 목소리로 읽는 것을 권한다. 배경음악은 쓰지 않는 게 안전하다. (저작권 문제를 피함)
- **출력:** 가로 1920×1080, mp4. 이메일 첨부 용량 제한을 KEIT에 확인한다.
