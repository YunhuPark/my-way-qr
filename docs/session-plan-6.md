# 6명 테스트 진행 계획

참가자 6명 기준. 과업(카페·민원·병원)과 화면(기본·내 방식)을 돌려 가며 배정해, **각 과업이 기본 화면 2번, 내 방식 화면 2번**씩 나오도록 균형을 맞춘 배정표다.

## 배정표 (참가자 코드 → 누가 몇 번째로 무엇을)
| 코드 | 1번째 과업 | 2번째 과업 | 시작 주소 |
|---|---|---|---|
| **P1** | 카페 · **기본 화면** | 민원 · **내 방식 화면** | `…/?test=1&pid=P1` |
| **P2** | 민원 · **기본 화면** | 병원 · **내 방식 화면** | `…/?test=1&pid=P2` |
| **P3** | 병원 · **기본 화면** | 카페 · **내 방식 화면** | `…/?test=1&pid=P3` |
| **P4** | 카페 · **내 방식 화면** | 병원 · **기본 화면** | `…/?test=1&pid=P4` |
| **P5** | 민원 · **내 방식 화면** | 카페 · **기본 화면** | `…/?test=1&pid=P5` |
| **P6** | 병원 · **내 방식 화면** | 민원 · **기본 화면** | `…/?test=1&pid=P6` |

`…` = `https://my-way-qr.onrender.com`

- 과업 카드: 카드 1 = 카페, 카드 2 = 민원, 카드 3 = 병원
- **누구를 P1~P6으로 할지는 섭외한 순서나 일정이 잡힌 순서대로 정하면 된다.** 이름과 코드의 대응표는 종이에 따로 적어 두고 기록지·동의서와 섞지 않는다.

## 파일럿은 어떻게 하나
6명이 전부라서 별도 파일럿 인원이 없다. **P1을 첫 세션으로 하되 정식 배정(카페 기본 → 민원 내 방식) 그대로 진행**한다.
- P1 이후 **진행 방식·문구·앱을 바꾸지 않았다면** P1 데이터를 그대로 분석에 포함한다.
- **바꿨다면** P1 데이터는 분석에서 제외하고(`--exclude P1`), 제외했다고 보고서에 한 줄로 밝힌다. 이 경우 분석 인원은 5명이 되어 배정 균형이 완전하지 않으니, 그 사실도 같이 적는다. (인원을 억지로 채우려고 대상이 아닌 사람을 추가하지 않는다.)

## 세션 한 번의 흐름 (약 20분)
1. **10분 전** `https://my-way-qr.onrender.com/`를 열어 서버를 깨운다. (잠들었으면 20~30초)
2. 시작 주소(위 표)로 연다. 맨 위에 `[테스트 모드: 참가자 P#]`이 보여야 한다.
3. 동의서 서명(이름 없이 서명만) → 사전 질문 → **내 화면 설정 만들기**(기록지 A) → 참가자 휴대폰으로 QR 확인
4. 노트북·태블릿에서 **"이 설정으로 키오스크 체험"** 버튼 → 위에 기록 패널이 나옴
5. **1번째 과업**
   - 배정표대로 **탭(카페/민원/병원)과 화면(기본/내 방식)을 먼저 고른다.** (시작하면 잠김)
   - 과업 카드를 건네고 **과업 시작** → 참가자 조작 → 완료 화면이면 자동 저장
   - 힌트를 주면 **도움 +1**, 포기하면 **중단**
6. 만족도 Q1~Q3 → **2번째 과업**(같은 방식) → 만족도 → 마무리 인터뷰 3문항
7. **CSV 내려받기**로 백업 (참가자마다 한 번)

## 세션 전 점검 (매번 30초)
- [ ] 같은 기기·같은 브라우저인가 (기록이 거기에만 저장됨)
- [ ] 기록 패널의 표에 **이전 참가자 기록이 쌓여 있는가** (정상. 지우면 안 됨)
- [ ] 리허설·연습 기록이 남아 있지 않은가 (남았으면 분석할 때 `--exclude`)
- [ ] 동의서·기록지·과업 카드 인쇄물이 있는가

## 결과 분석 (10/27)
```
python tools/analyze.py 받은_CSV_파일들.csv --exclude DEV
```
- 여러 CSV를 한 번에 넣어도 되고, 같은 기록이 겹쳐 있으면 한 번만 센다.
- 출력: 데이터 점검 → 조건별 요약 → 과업×화면 → 참가자별 표
- **데이터 점검**에서 "한 사람이 기본 1건 + 내 방식 1건이 아님"이 나오면 보고서에 쓰기 전에 원인을 먼저 확인한다. (중복 시작, 중단 기록 등)
- 도움 요청은 기록 패널의 **도움 +1**에만 잡힌다. 기록지에 적은 만족도·인터뷰·5초 이상 멈춤은 이 스크립트와 별도로 정리한다.

## 보고서에 쓸 때
- 비율보다 **사람 수**로 쓴다. 예: "도움 없이 끝낸 시도는 기본 화면 N건 중 A건, 내 방식 화면 N건 중 B건"
- 같은 사람이 서로 다른 과업을 했으므로 **과업 난이도 차이가 섞인다**는 점을 한 줄 밝힌다. (과업×화면 표를 함께 제시)
- 표본이 작으므로 "소규모 사전 탐색(N=6)"이라고 쓰고, 통계적 유의성은 주장하지 않는다.
- 개별 값(참가자별 표)을 부록이나 본문에 그대로 공개한다.
